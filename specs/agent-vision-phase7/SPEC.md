# Execution Orchestrator v1
One synchronous Application-layer task entry for a named active Workflow Family. Pin family/device/profile/version/generation; caller-generated task_<32 lowercase hex> ID; same ID returns persisted outcome, never replays. Entire execution under existing cross-process workspace operation lock; internal locked Runtime/Selector methods share that lock; no nesting. Use the previously qualified binding from registered proof; Runtime always revalidates live profile, fresh state and target. No new qualification by assuming the initial state already holds. Journal task before any action; deterministic distinct child run IDs; reject collisions before action. Child runs retain independent durable receipts. Crash leaves running journal; duplicate converts to interrupted under lock, reconciles available child receipts for inspection only, never resumes.
Execute primary once. If complete => completed. Automatic recovery permitted ONLY for first-step PRECONDITION_FAILED, zero completed steps, action_outcome not_attempted, no action receipt/target, and unambiguous state. Use existing selector to capture fresh evidence and choose unique enabled exact-version route; require its destination equals primary initial state. Child runtime revalidates fresh state; only one recovery attempt. Recheck parent initial guard on actual child final frame. Only then start primary once again; successful full primary is completed; otherwise needs_agent. No partial-prefix replay, uncertain click retry, recovery chaining, automatic LLM, promotion, or workflow editing. Zero/no/ambiguous match and all other failures yield structured handoff. Max 3 child runs; max 1 recovery, max 1 primary restart; each existing Runtime per-step capture budget applies, not a hard wall-clock task timeout. Lock serializes cooperating adapters, not external device control.
Task journal stored in STORE/orchestrator/tasks; references run IDs, selection frame, generation, reasons and last observed/confirmed state; bounded summary/inspect/list. Explicit auto_recover boolean (default false), caller supplies true for automatic recovery/restart. Registry inactive or generation mismatch fails closed. No arbitrary user goal parsing, scheduler or daemon. Existing CLI/MCP contracts preserved.

## Transport acceptance note

This version does not implement a detached execution API or promise completion after disconnect.
