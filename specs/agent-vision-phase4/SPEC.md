# Workflow Runtime v1
Application-layer deterministic execution of validated Phase 3 click-only bundles. No LLM calls, no recovery/replanning, no arbitrary commands, no direct coordinate replay. Explicit source device, immutable workflow ID, explicit Android profile (foreground package, versionCode, display rotation, system locale, UI mode). Qualify read-only against source geometry, initial state guard and unique first target; persist content-addressed binding. Each run requires binding ID and caller-generated unique run ID; duplicate requests return existing receipt, never execute twice. Bind only same device as source; other platforms not supported in v1. Theme/app locale inferred only through visual guards, not independently readable. Check actual profile before/after captures and immediately before click. Package identity must agree with focused window and resumed activity. Validate source bundle/evidence and load exact SHA templates before action.
Exclusive workspace operation lock across run, no nested Recorder lock; dedicated durable runtime journal (atomic JSON per run), separate from exploration events. Store protected live frames and newly scoped refs. No historical coordinates/refs in execution. Each step captures fresh full frame, checks geometry, classifies exactly one expected state (all guards, NMS uniqueness), finds unique target, verifies profile and freshness, writes durable action_pending before one ActionService click. Persist action receipt, then poll fresh frames for destination guard until declared timeout/capture cap. Unknown transient frames may be observed during wait only; unexpected known state/ambiguous state fails closed. Never retry click. Only final verified destination yields completed; action receipt alone is not success. On exception stop with structured reason, last frame, step and action outcome; no automatic resume. Crash while running is unknown, inspect before new request. Per-step timeout is checked at capture boundaries; existing ADB subprocess deadlines can overrun nominal wait but remain bounded. External device controllers are not locked by workspace lock.
CLI/MCP qualify/run/inspect/list; run response bounded (summary with step receipts and latest frame; inspect full journal). Live qualification is distinct from builder offline validation. Source session and bundle unchanged. Acceptance: original regression + tests for mismatch/ambiguity/timeout/failure/idempotency/interruption/tamper; actual MuMu reversible repeated path and independent audit; wrong profile rejection without click. No new Orca projects, no cloud sync.
